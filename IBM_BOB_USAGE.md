# IBM Bob Technology Usage

## Project: CareerAI Copilot

**Hackathon:** SkillUp Hackathon in collaboration with IBM SkillsBuild

**Track:** Student AI Track

**Team:** CareerForge AI

**College:** Pragati Engineering College

---

## 1. Introduction

CareerAI Copilot is an AI-powered career and job-readiness assistant designed to help students identify suitable career paths, understand skill gaps, create learning roadmaps, and prepare for interviews.

IBM Bob was used as an AI-powered development assistant during the development of this project.

---

## 2. Why We Used IBM Bob

Developing an AI-powered application requires planning, coding, debugging, testing, user-interface development, and documentation.

IBM Bob helped accelerate these activities by providing AI-assisted development support throughout the project lifecycle.

---

## 3. Project Planning

IBM Bob was used to break the project idea into smaller functional modules.

The major modules identified were:

1. Resume Analyzer
2. GitHub Analyzer
3. Skill Analyzer
4. Career Recommendation Engine
5. Skill Gap Analyzer
6. Learning Roadmap Generator
7. Mock Interview Module
8. Interview Feedback
9. Job Readiness Score
10. Career Assistant

## 6. AI Workflow Development

IBM Bob assisted in designing AI workflows for the application's core features.

### Resume Analysis

The AI workflow extracts relevant information such as:

* Technical skills
* Programming languages
* Projects
* Education
* Experience
* Certifications

### Career Recommendation

The extracted profile is used to identify suitable career paths.

Example:

```text
Student Skills:
Python
Machine Learning
SQL
Git

Recommended Career:
AI / ML Engineer
```

### Skill Gap Analysis

The system compares the student's current skills with skills required for the selected career.

Example:

```text
Current Skill       Status

Python              ✓
Machine Learning    ✓
Deep Learning       ✗
NLP                 ✗
TensorFlow          ✗
```

### Learning Roadmap

The system generates a structured roadmap based on identified skill gaps.

### Mock Interview

IBM Bob assisted in developing workflows for generating interview questions and providing feedback on student answers.
