# CareerAI Copilot 🎯

### Personalized AI Career & Job Readiness Assistant

CareerAI Copilot is an AI-powered career guidance platform designed to help college students understand their skills, identify career opportunities, discover skill gaps, create personalized learning roadmaps, and prepare for interviews.

## 🏫 Hackathon

**SkillUp Hackathon in collaboration with IBM SkillsBuild**

**Track:** Student AI Track

**College:** Pragati Engineering College

**Team:** CareerForge AI

## 🎯 Problem

Many students struggle to identify suitable career paths and understand which skills they need to become job-ready. Students may have a resume, GitHub projects, and access to learning resources, but often lack personalized guidance connecting their current skills to their desired career.

## 💡 Solution

CareerAI Copilot provides a single AI-powered platform that analyzes a student's profile and provides personalized career guidance.

### Key Features

* 📄 Resume Analysis
* 💻 GitHub Skill Analysis
* 🎯 Career Recommendations
* 🔍 Skill Gap Analysis
* 🗺️ Personalized Learning Roadmap
* 📚 Learning Resource Recommendations
* 🎤 AI Mock Interviews
* 📝 Interview Feedback
* 📊 Job Readiness Score
* 💬 Career Guidance Assistant

## 🔄 Workflow
